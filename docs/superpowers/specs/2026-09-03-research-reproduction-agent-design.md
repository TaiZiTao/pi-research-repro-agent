# 单论文科研复现 Agent 简版设计

## 目标

在 Pi Agent 上实现一个面向求职展示的单论文科研复现 Coding Agent。用户可导入本地 PDF，或通过 MCP 搜索并选择论文；Agent 能基于可验证证据回答问题，并完成代码获取、最小复现、报错修复和结果整理。

## 范围

主线功能：

- 单论文总结、证据问答、局部翻译和模拟审稿。
- 论文搜索与开放 PDF 下载 MCP。
- 官方仓库识别；无仓库时进行明确标注的最小复现。
- 复现计划、受限执行、最多 3 轮自动纠错和断点恢复。
- QLoRA 工具调用微调，以及 Base/QLoRA 对照评测。

暂不实现桌面 UI、多论文综合分析、云端部署和论文全部实验复现。

## 复用现有实现

以下代码直接保留：

- PDF 校验、托管复制、PyMuPDF 解析和页码证据块。
- SQLite 项目持久化、隔离工作区和任务状态机。
- `paper_analysis`、`reproduction_planning`、`reproduction_execution` 三个 Skill 骨架。
- Pi 的 `research_search_evidence` 工具及当前项目绑定。
- `import`、`list`、`search` CLI。

现有关键词检索作为回退方案，并升级为 BM25 与多语言向量检索的混合 RAG。

## Workflow

```text
本地 PDF / MCP 搜索并选择论文
→ PDF 解析与混合 RAG
→ 总结、问答、翻译或审稿
→ CitationVerify 校验引用
→ 搜索并核验官方仓库
→ 生成复现计划
→ 沙箱执行与报错修复（最多 3 轮）
→ 指标校验与复现报告
```

找不到官方仓库时，Agent 可以创建最小可运行实现，但必须标记为“Agent 最小复现”，不能冒充官方代码。

## 四层约束机制

- 模型层：输出结构化答案和引用；证据不足时拒答。
- 工具层：工具绑定当前项目，参数使用 Schema 校验，命令限制在复现工作区并设置超时。
- 校验层：检查 `paper_id/page/chunk_id`、引用文本和真实运行产物；校验失败时重检索，连续失败后停止。
- 来源层：保存论文来源、仓库 URL、commit hash、许可证和匹配依据。

## QLoRA

使用 Qwen2.5-Coder-1.5B-Instruct，在 RTX 4060 8GB 上进行 4-bit QLoRA。训练目标是工具选择、参数填写、证据不足拒答和执行报错纠正，不训练论文知识。

先用 100 条轨迹验证训练链路，再构建约 800～1200 条经过检查的多轮轨迹。训练、验证和测试集按论文及错误类型隔离。

## 评测

在相同提示词、工具和测试集下比较 Base 与 QLoRA：

- Tool-needed F1、工具选择准确率。
- 参数合法率和参数内容准确率。
- 报错恢复率、无证据拒答率。
- 引用格式合规率和端到端任务完成率。

所有简历指标必须来自实际评测结果。

## 完成标准

- 一篇真实论文可以完成导入、证据问答、仓库判断和最小复现。
- 回答引用可由 CitationVerify 验证。
- 至少展示一次真实报错后的自动修复。
- 生成复现报告、日志、产物以及 Base/QLoRA 对比报告。
- 使用 Pi 对话、CLI、README、流程图和录屏展示，无需桌面 UI。
